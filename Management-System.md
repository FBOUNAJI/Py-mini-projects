# Student Management System 📝

 A command-line Student Management System built with Python and SQLite. 
It allows users to add, view, search, update, and delete student records stored in a local database.


## Technologies Used

* **Python**
* **SQLite**
* **sqlite3**
* **SQL**
* **CRUD operations**
* 

Through this project, I practiced:

* Connecting Python to a SQLite database
* Creating database tables
* INSERT, SELECT, UPDATE, and DELETE
* Extracting data from nested dictionaries
* Using SQL queries with Python
* Fetching data with fetchall() and fetchone()
* Building a menu-driven CLI application
